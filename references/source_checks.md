# Literature scope checks

Primary sources checked for the claims used in the manuscript. Crossref metadata in this directory verifies bibliographic fields, not scientific conclusions. No published dataset is represented as having been reanalyzed in this study.

| Source | Relevant support and boundary |
| --- | --- |
| [Brennan 2016 publisher excerpt](https://assets.press.princeton.edu/chapters/s10843.pdf) | Philosophical context and the hobbit, hooligan and vulcan taxonomy. The four citizen categories in the simulation are author-defined, not Brennan's empirical types. |
| [Cesa-Bianchi and Lugosi 2006 author book page](https://cesa-bianchi.di.unimi.it/predbook/) | Established prediction-with-expert-advice framework. No regret bound for this restricted, unbounded-loss model is inferred. |
| [DeGroot 1974](https://doi.org/10.1080/01621459.1974.10480137) | Opinion pooling and consensus precede this proposal. |
| [Hegselmann and Krause 2002](https://jasss.soc.surrey.ac.uk/5/3/2.html) | Bounded-confidence opinion dynamics. The current implementation is one synchronous step per fresh observation. |
| [Lorenz 2010 author preprint](https://arxiv.org/abs/0801.1399) | Heterogeneous confidence bounds are prior work, not a PKD innovation. Correct DOI: 10.1002/cplx.20295. |
| [Golub and Jackson 2010](https://doi.org/10.1257/mic.2.1.112) | Conditions on social networks for aggregation; these conditions are not automatically met by PKD. |
| [Flanigan et al. 2021](https://www.nature.com/articles/s41586-021-03788-6) | Citizen-assembly selection and individual inclusion fairness. PKD's largest-remainder stratification does not inherit their fairness guarantees. |
| [Hong and Page 2004 author PDF](https://sites.lsa.umich.edu/scottepage/wp-content/uploads/sites/344/2015/11/pnas.pdf) | Diversity in collective problem solving under stated assumptions; not a theorem about independent Gaussian measurement averaging. |
| [Mellers et al. 2014 author PDF](https://faculty.wharton.upenn.edu/wp-content/uploads/2015/07/2014---psychological-strategies-for-winning-a-tournament.pdf) | Empirical forecasting experiment supports discussion of training, teaming and tracking. Its participant data do not calibrate this simulation. |
| [Edmonds et al. 2019](https://doi.org/10.18564/jasss.3993) | Distinguishes modeling purposes; used to frame an exploratory mechanism study. |
| [Grimm et al. 2020](https://doi.org/10.18564/jasss.4259) | ODD model description structure; compliance is not empirical validation. |
